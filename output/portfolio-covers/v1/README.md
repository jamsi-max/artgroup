# ART Group — архитектурные обложки, v1

Созданы 11 постеров через встроенный инструмент **image_gen**, по одному для каждого активного проекта. Общий язык: угольный фон, тёплый ivory, объёмный архитектурный коллаж, тонкие чертёжные линии и красная графическая плоскость/маршрут. Материалы каждого проекта служили референсами; первый постер служил референсом стиля для остальных.

Это художественные AI-интерпретации, а не технические реконструкции или документальные фотографии. Красные плоскости, разрезы и чертёжные фрагменты — редакционная графика, не утверждения о реализованных элементах. Внутри изображений нет названий, дат и маркетинговых утверждений; название и стадия проекта должны оставаться живым текстом сайта на RU/EN. Постеры подключены к карточкам сайта. Исходные изображения и прежние обложки сохранены внутри соответствующих попапов.

## Просмотр

## Воспроизводимость и проверка

- [Полный набор промптов и привязка к исходникам](prompts-and-manifest.json). Пути референсов указаны относительно корня репозитория.
- [Проверка размеров, декодирования и веса](asset-validation.json).
- `export-assets.py` повторяет WebP-экспорт и сборку контактного листа из PNG; требует Pillow и Arial, доступных в текущей среде.
- «Ухоглаз» уточнён вторым проходом: уменьшен павильон, убран выдуманный многоуровневый атриум. Первый вариант сохранён в `variants/09-ear-eye-v1.png`; выбран `09-ear-eye-v2.png`. Оба промпта записаны в манифесте.

Постеры подключены в `index.html`: рабочие WebP размещены в `img/portfolio/covers/v1/`, доступны варианты 960 и 1536 px через `srcset`. Alt переведены на RU/EN. CSS задаёт индивидуальное кадрирование; оригинальные материалы сохранены в историях проектов.
